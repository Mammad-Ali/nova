NOVA — КАК ЗАПУСТИТЬ
====================

ШАГ 1. Распакуйте архив ЦЕЛИКОМ.
   Правый клик по архиву -> "Извлечь все" (Extract all).
   Запускать прямо из архива НЕЛЬЗЯ: приложение не найдёт свои файлы.

ШАГ 2. Откройте распакованную папку и запустите Nova.exe

ШАГ 3. Windows покажет синее окно "Windows protected your PC".
   Это нормально: у приложения нет платного сертификата Microsoft.
   Нажмите "More info" (Подробнее), затем "Run anyway" (Выполнить
   в любом случае).


ВАЖНО
-----
Файлы .dll и папку data не удаляйте и не переносите отдельно —
без них Nova не запустится. Перемещать нужно всю папку сразу.

Чтобы приложение было под рукой: правый клик по Nova.exe ->
"Закрепить на панели задач".
